S聯賽秋季賽｜選手圖鑑
資料核對日期：2026-10-23

收錄8支隊伍、49位選手：20位競速選手、29位道具選手。
選擇隊伍後，可切換「競速／道具／總覽」；總覽以扇形卡組展示該隊全部選手。
滑鼠移入卡牌可將卡片展開；點擊或輕點可放大檢視。
也可點選下方選手名字，或使用Tab、方向鍵瀏覽，以Enter或空白鍵開啟放大檢視。
放大檢視可按關閉、Esc或點背景關閉，並回到原卡牌位置。
電腦版為左卡牌、右個人簡介；手機版為上卡牌、下個人簡介。
可切換「立體卡牌／原卡牌」。立體模式保留紫金原設計及真實人像，以淺層景深、細微視差、卡面反光和陰影呈現厚度。
滑鼠移動會帶動卡牌角度；觸控裝置使用固定角度，系統減少動畫設定會停用跟隨動畫。
競速組已有16位本名、10位生日月日；道具組已有17位本名、14位生日月日。
未核實欄位顯示「待補充」，不填猜測值，不推算出生年份或年齡。簡介附公開來源連結。

照片狀態：20位競速選手已有卡牌；目前28位道具選手使用人像，廣州狼隊.Lin暫用待補圖。
