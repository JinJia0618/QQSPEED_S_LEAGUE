S聯賽秋季賽｜選手圖鑑
資料核對日期：2026-11-01
照片與排列更新日期：2026-10-24

收錄8支隊伍、49位選手：20位競速選手、29位道具選手。
選擇隊伍後，可切換「競速／道具／總覽」；總覽依指定順序排列，TOP位於中央最前方，左右兩側逐層退後。
滑鼠移入卡牌可將卡片展開；手機左右滑動卡組可切換、凸顯選手，輕點可放大檢視，卡組保留上下捲動。
也可點選下方選手名字，或使用Tab、方向鍵瀏覽，以Enter或空白鍵開啟放大檢視。
放大檢視可按關閉、Esc或點背景關閉，並回到原卡牌位置。
電腦版為左卡牌、右個人簡介；手機版為上卡牌、下個人簡介。
放大後使用單一預覽，保留紫金原卡外觀；滑鼠移動或手指拖曳可帶動人物微動、卡牌細微角度與卡面流光。
邊框及對角採低強度淡金色呼吸柔光。系統開啟減少動畫時，停用跟隨、流光與呼吸動畫，保留靜態微光。
大廳背景直接沿用卡牌原圖中的金黃色蝴蝶，保留光翼、亮紋與光尾，緩慢飄動；手機縮小並移至邊緣，減少動畫時保持靜態。
競速組已有19位本名、10位生日月日與11位星座；道具組已有19位本名、15位生日月日與15位星座。
星座依已公開生日的常見西洋星座日期區間換算，或採官方介紹直接列明資料；交界日期可能因出生年份與時間不同而有差異。
本輪新增的4位本名採官方選手介紹搜尋索引並交叉核對，原文全文尚未核讀；個人簡介有標示此限制。其餘候選不填入確定欄位。
未核實欄位顯示「待補充」，不填猜測值，不推算出生年份或年齡。簡介附公開來源連結。

照片狀態：20位競速選手與29位道具選手均已有照片卡牌。
2026-10-24依使用者提供的16張定裝照及逐張ID對應，替換XROCK、廣州狼隊、Wz、RW全部道具選手；包含Lin。16張均重新以Canva去背，依臉部大小等比例縮放，並同步更新動畫人像圖層。
AG.飛雪使用較早公開定裝照。個人簡介保留照片說明。

本版已移除打Call、票數、排行榜及瀏覽器應援紀錄功能。
卡牌沿用已確認的人像、比例及朝華標題B中文字體。
